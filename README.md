# Common Ground

A disaster community-response platform for county and city emergency management, NGOs and states: resident damage and needs reporting, staff review, needs sharing with partners, public "Find help", missions and dispatch, a field app, FEMA declaration support, a CJIS enclave, ICS/EOC functions and AI assistance.

The product name is configuration (`PRODUCT_NAME`, ADM-03). "Common Ground" is the current working name.

**Status:** layers 1 (platform foundations), 2 (resident intake, review, verification) and 3 (needs board, partner sharing with consent, public "Find help") built, tested and approved (2026-10-12 and 2026-10-13); layer 4 (missions, dispatch board, field app) merged; layer 5 (the CJIS enclave) merged; layer 6 (FEMA package and official reports) merged; the partner work before layer 7 merged; layer 7 (AI assistance, the command window, facilities and recommendations) built, report in `docs/plans/layer-7-report.md`. See `docs/plans/layer-7-report.md`, `docs/traceability.md` and the newest `docs/plans/layer-N-status.md`. Build order follows SCL-14, one layer at a time; `CLAUDE.md` has the rules for resuming work.

## Start the stack

Requirements: Docker Desktop (Compose v2), Node 24 (`.nvmrc`), pnpm 10 (`corepack enable`). On Windows read [Windows (Docker Desktop)](#windows-docker-desktop) first.

```sh
scripts/init-env.sh          # writes .env with random local secrets (never committed)
docker compose up -d --wait  # builds images, starts every service, waits for health
```

The first `up` builds seven images and pulls six more; 10–20 minutes on a laptop is normal. `--wait` returns 0 once every service is healthy and the one-shot jobs (`migrate`, `keys-init`, `seed`, `seed-load`) have finished; `docker compose ps -a` shows the state at any time. The worker then provisions the nine synthetic organizations (sign-in realms, cast accounts) for another minute or two; `docker compose logs -f worker` shows it, and the test suites wait for it on their own.

Then open:

### Report damage as a resident

Open `https://localhost/county/westwind` (the root forwards there; `DEFAULT_TENANT` and `DEFAULT_EVENT` in `.env` change it). The flow asks one question at a time from the published graph, keeps answers on the device encrypted, works offline until it can send, and ends with a reference number such as `KXMR-4827`. Other entry points: `…/westwind/kiosk` (assisted entry by a helper, cleared from the device when done), `…/westwind/resume` (continue a paused report with its code), `/county/my-report` (reference number + the phone or email given → one-time code → status, consent, corrections, withdrawal; one-time codes to email land in Mailpit at `http://localhost:8025`). Photos upload straight to object storage through `https://objects.localhost` (trust the same local CA; browsers resolve `*.localhost` themselves). A browser that cannot reach that host, because its certificate is not trusted or a network blocks it, sends the photo through the gateway instead, so photos still arrive; trusting the local CA makes the direct path work.

### Find help as the public

Open `https://localhost/county/help` (no sign-in). It lists open shelters, feeding sites, PODs and other published sites nearest to a ZIP code, an address or the browser's location, with status, hours, services, pets, accessibility, power for medical devices, languages, transit and when each was last confirmed; a full or closed site names the next nearest open one. The map loads only when asked. `?lang=es` switches to Spanish; the print and poster views are buttons on the page. The same records feed `/api/public/help/county` (JSON), `/sites.geojson`, `/hsds.json` (Open Referral for 211 centers), `/widget.js`, `/media?lang=en` (media sheet) and `/resources/<slug>` (published resources with their own pages). Confidential sites and sites past their confirmation window appear on none of them (PUB-03, PUB-05).

## Text and call the county (simulator)

Without Twilio, the API plays the phone on synthetic data. Text the exercise county's number (`+13145550100`) from any number:

```sh
curl -sk https://localhost/api/webhooks/simulator/sms -H 'content-type: application/json' \
  -d '{"from":"+13145550199","to":"+13145550100","body":"DAMAGE"}'
# → {"replies":["Westwind County Emergency Mgmt: You're signed up …","… Is anyone in danger right now?\n1 Yes …"]}
```

Reply with the numbers (`2`, `1`, …), `BACK`, `SKIP`, `HELP`, `STOP`, or `DAÑOS` for Spanish; `SEND` at the end returns the reference code. `SHELTER 63001` (or `REFUGIO 63001`) answers with the three nearest open sites; `NOSHARE KXMR-4827` from the reporter's phone stops sharing that report with partner organizations (both keywords approved for the carrier submission, `docs/06`). A plain text from a phone that received a staff update in the last week is kept on the report as a reply. A call starts with `{"from":"+13145550199","to":"+13145550100","step":"start"}` on `/api/webhooks/simulator/voice` and continues with `step` from the answer plus `digits` or `speech`. Texts the worker sends (confirmations, one-time codes) go to the in-process simulator and are recorded in `cg.message`. To use real numbers set `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN` and `WEBHOOK_PUBLIC_BASE` in `.env`, add the county's verified number to `cg.channel_number`, and point Twilio's webhooks at `/api/webhooks/twilio/sms`, `/voice` and `/status` through a secured tunnel (`docs/06`).

### Review reports as staff

Sign in as `priya.assessment@example.org` (`county`). **Review queue** lists reports with need signals first (unsafe, no shelter tonight, medical, displaced), then the oldest; filters cover event, state, verification, channel, flags and a reference number. A report opens to its answers grouped as the resident saw them, photos (links only for roles with the evidence category, blurred faces and plates when a detector is configured), needs, consent and the version history. Decisions (approve, reject, needs information, duplicate, supersede, reopen), the verification level and the FEMA degree of damage each ask for confirmation and a reason; the FEMA matrix next to the form is the official wording (DEC-03). A helper cannot approve a report they entered (guardrail G4). **Intake setup** shows each open event's resident link, kiosk link, text keywords and a QR code to print, and the question-graph versions: a new draft must pass the reading-level and tone rules before it can be published. **Assisted report** opens the kiosk flow for an event in a new tab. **AI use register** lists every AI feature, its provider and its human checkpoint; administrators evaluate the provider and switch features on or off there (layer 7). Every AI feature runs on OpenAI (ADR-0043) and stays off until `OPENAI_API_KEY` is set and the tenant's languages pass the evaluation; without the key the manual paths run and nothing calls a fake.

### The CJIS enclave (layer 5)

The `cjis-*` services run on their own internal network `cg_cjis` with their own database, keys and Keycloak (ADR-0021). Only `cjis-gateway` is reachable, at https://localhost:8443 on the loopback address (`CJIS_HTTPS_PORT`, `CJIS_BIND_ADDRESS` in `.env`); the enclave database, keys and identity administration publish nothing. The platform holds only an opaque reference per mission and the console only links to the enclave (ADR-0038). It holds **no real criminal-justice information** until it runs in an authorized government cloud and has passed the state CJIS audit (SCL-12).

- In the console, `liaison@example.org` (`county`, law-enforcement liaison) sees the "Law enforcement (CJIS)" panel on a mission: the exercise mission "Law-enforcement support at the Commercial Row distribution point" is already linked; **Link to the CJIS enclave** links another one with a reason; **Open in the CJIS enclave** opens the enclave's own address in a new tab. Everyone else who can read the mission sees "Restricted: CJIS".
- The enclave asks for its own sign-in: password, then a passkey (ADR-0036). The exercise accounts (synthetic stacks only) are in `services/cjis-api/src/provision/exercise.ts`, all with the password `Westwind-Exercise-2026!`: at the Westwind County Sheriff's Office (exercise) `deputy.reyes`, `sgt.hollis`, `records.lane`, `tac.admin`, `laso` and `auditor` `@sheriff.example.org` (plus `deputy.lapsed` and `deputy.pending`, deliberately not qualified, and `lockout.drill`); at the city police department `officer.vance`, `admin` and `laso` `@police.example.org`. The test client `cjis-tests` signs in with password and a time-based code instead; `tests/support/cjis.ts` shows how.
- A new enclave account is created by an agency administrator (**Accounts**: screening dates, then a role request), approved by a second administrator (**Approvals**), and activated with a one-time password shown once to hand over in person.

### Official numbers, the FEMA package and integrations (layer 6)

Every official figure comes from one counting rule (`packages/reporting`): only approved, verified records count, one home counts once, and what is left out is shown apart, never dropped (DCL:DEC-03). Sign in as `dana.director@example.org` (`county`): **Declaration data** keeps the incident period and the 30-day clock, outages, official casualty counts and public damage sites, chooses representative photos (only detector-blurred ones, none until a detector is enabled) and makes the **damage assessment package** (a ZIP with the PDF, the FEMA forms as CSV, the GeoJSON layer and a README naming the mapping versions; for the whole event or one city). **Official reports** are drafted, reviewed by someone else and issued with a reason; the issued copy is frozen and written under object lock, and is exported as PDF or CSV. **Joint assessment** draws the FEMA/state sample (a `fema_validator` role is time-limited), **Shared declaration figures** is the state liaison's counts-only view under a signed agreement, **FEMA form mappings** puts a new FEMA edition in force without a release, **Metrics** and **Equity** show the shared metrics and the coverage and wait-time gaps (counts under 11 hidden), and the **Situation map** shades tracts by damage, coverage or the Census profile. Every PDF is PDF/UA-1.

**Partner counts** (decided 2026-10-15): the Declaration data screen and every draft official report have a **Roll up all partner counts** checkbox, ticked by default. Untick it to choose which partner organizations and which counts (needs met, meals and services, people sheltered, teams, donated hours and equipment) are included; the figures say what they include, and an issued report keeps the choice. The counts come from each partner's own records as numbers only (`cg.partner_counts`, migration 0053).

**API keys and webhooks** (Administration, `admin@example.org` asks, `security.admin@example.org` approves; never the same person): a key is shown once and reads the PDA feature service at `https://localhost/api/gis/<county>/pda/FeatureServer` (add it in ArcGIS or QGIS with the key as `token`); a webhook (HTTPS, a public host name) is told when a report is issued or an export is ready, signed per Standard Webhooks (ADR-0042). Residents download their own copy of their report from **my report**; the public media sheet is also a PDF (`/api/public/help/<county>/media.pdf`).

### AI assistance, the command window and recommendations (layer 7)

People decide; AI suggests, drafts and interprets, and every task still works with AI off (AI-01, AI-10). Every AI feature runs on OpenAI (ADR-0043) and needs the secret `OPENAI_API_KEY` in the environment. It also needs an administrator to evaluate the provider and switch the feature on with a reason (**AI use register**, `admin@example.org`). Without the key the AI features are off and the manual paths run. The register also shows:

- open AI health alerts, which are raised when people correct a feature too often or its calls fail;
- fairness alerts for the damage severity suggestion, with the reviewers' agreement by hazard, home type and income band.

Alerts never switch a feature off. `docs/ai-rmf.md` maps all of this to the NIST AI RMF for procurement reviews.

**Command window.** Press Ctrl+K (Command+K on a Mac) or the "Ask or command" button in any workspace.

- Shorthand works without AI. Try `/needs open`, `/missions unassigned`, `/remind in 30m call the shelter` or `/help` (`/ayuda` in Spanish).
- Plain words are read into shorthand when the feature is on.
- A change is shown as a plan to confirm, and it can be undone within its window.
- Recent commands are kept for 30 days unless the device is marked shared.
- The field app has the same screen, and Find help has a plain "Ask a question" box that uses no model.

**Facility registry and recommendations.**

- _Facility registry:_
  - `jen.coad@example.org` (`coad`) proposes a place, and `dana.director@example.org` approves it in **Facility approvals**;
  - the public can offer a place from Find help.
- _Recommendations:_ `luis.masscare@example.org` asks for a shelter, feeding stops, a POD with walk-up points or a MARC. Each answer comes with its reasons, unknowns, the places set aside, the age of its inputs and an equity check. A named person accepts, edits or rejects it with a reason. The rules and planning factors are in `docs/recommendations.md`.
- _Resource discovery:_ gathers partner posts, county feeds and, when switched on, web search, for a person to decide (`docs/discovery.md`).

**Drafting.**

- Official reports and the declaration's Form 010-0-13 Boxes 8–9 can be drafted from their facts. Every figure is checked against the facts it cites, and a draft that fails is never shown.
- The PIO (`tomas.pio@example.org`) can draft the social post, the radio loop and the amateur-radio readout for a site, render the radio script as audio labelled as computer-generated, and download a social card.

**Field.** In the field app (`rowan.field@example.org`):

- the conversation note-taker records only after the survivor consents in their language and keeps only the confirmed note, with the audio deleted;
- "Hand-over for the next shift" drafts a hand-over from the shift's own records at check-out;
- "Live translation" translates general conversation between English and Spanish, with an interpreter one tap away. Consent, legal and medical conversations always go to an interpreter.

**Photos.** Where the county switches it on, reviewers see an "AI suggestion — not verified" degree of damage after the FEMA matrix. They set the degree themselves, and their agreement is recorded. The review queue puts people's needs first and the suggestion second. A photo that looks the same as one on another report is flagged for a person.

Maps (SCL-13) are opt-in because the first build downloads the Missouri OpenStreetMap extract: set `COMPOSE_PROFILES=maps` in `.env` for the geocoder and run `docker compose --profile maps-build run --rm tiles-build` once for vector tiles.

Behind a corporate proxy that inspects TLS, pass its CA to the builds: `docker compose build --build-arg HTTPS_PROXY=... ` and `--secret id=extra_ca,src=/path/ca.pem` (see `infra/node/Dockerfile`).

### Windows (Docker Desktop)

Docker Desktop runs the stack in WSL 2 (Settings → General → _Use the WSL 2 based engine_, on by default). Pick one of two ways to work.

**Recommended: work inside WSL 2.** The shell scripts, pnpm and every test then run unchanged, and builds are several times faster than from a Windows folder.

1. In PowerShell once: `wsl --install -d Ubuntu` (reboot if asked). In Docker Desktop → Settings → Resources → _WSL integration_, enable Ubuntu and Apply.
2. Open the Ubuntu terminal and clone inside the Linux file system (your home directory, not `/mnt/c/...`):

   ```sh
   git clone https://github.com/Mennelabs/EOC-Application.git ~/common-ground
   cd ~/common-ground
   scripts/init-env.sh
   docker compose up -d --wait
   ```

3. For the checks, install Node 24 in Ubuntu (nodejs.org → Download → Linux, or `nvm install 24`), then `corepack enable && pnpm install`.
4. Windows browsers reach the stack at the same URLs (https://localhost/ and so on).

**PowerShell only.** The stack runs the same; the shell scripts (`backup.sh`, `restore.sh`, the drills) and `pnpm test:e2e` need the WSL or Git Bash shell.

```powershell
git clone https://github.com/Mennelabs/EOC-Application.git
cd EOC-Application
.\scripts\init-env.ps1        # blocked by the execution policy? powershell -ExecutionPolicy Bypass -File scripts\init-env.ps1
docker compose up -d --wait
```

For the checks install Node 24 LTS from nodejs.org (the installer adds corepack), then `corepack enable` and `pnpm install` in the repository.

**Trusting the local certificate (optional).** Browsers warn once about Caddy's local CA. To trust it in Edge and Chrome: `docker compose cp gateway:/data/caddy/pki/authorities/local/root.crt .` then `certutil -addstore -user Root root.crt` (Firefox keeps its own store: Settings → Certificates → Import).

**When it does not start**

- `required variable PRODUCT_NAME is missing a value`: `.env` is missing; run the init script in the repository folder.
- A clone made before `.gitattributes` existed may hold CRLF line endings. Symptoms: `db`, `cjis-db` or `keys-init` exit at once with `/bin/sh^M: bad interpreter`, `set: illegal option -` or `: not found`. Fix, in the repository folder (`.env` is untracked and survives):

  ```powershell
  git config core.autocrlf false
  git rm -r --cached -q .
  git reset --hard
  docker compose down -v
  docker compose up -d --wait
  ```

- Ports 80 and 443 must be free for the gateway; `bind: An attempt was made to access a socket in a way forbidden by its access permissions` means another program or a Hyper-V reservation holds one. Find the holder with `netstat -ano | findstr ":443 "` then `tasklist /FI "PID eq <pid>"`; IIS (_World Wide Web Publishing Service_) and VMware Workstation's shared VMs are the usual ones. The development ports (5432, 5672, 15672, 9000, 9001, 8200, 8081, 8025) can be moved in `.env` with `DB_PORT`, `QUEUE_PORT`, `QUEUE_UI_PORT`, `OBJECTS_PORT`, `OBJECTS_UI_PORT`, `KEYS_PORT`, `IDP_PORT` and `MAIL_UI_PORT`; `netsh interface ipv4 show excludedportrange protocol=tcp` lists Hyper-V's reserved ranges.
- The stack wants about 6 GB of memory. Raise WSL 2's share in `%UserProfile%\.wslconfig` (`[wsl2]` then `memory=8GB`), then `wsl --shutdown` and restart Docker Desktop.
- `container common-ground-<service>-1 exited (<code>)` or a service that never becomes healthy: `docker compose ps -a` shows which one and `docker compose logs <service>` why.
- `docker compose ps -a` and `docker compose logs --no-color > compose-logs.txt` are what to share when it still fails.

## Seed data

The `seed` service writes the synthetic county (tenants, areas, parcels, facilities, personnel, resident reports) to the `seed_data` volume; `seed-load` loads the WESTWIND hierarchy, shipped role templates and the console cast into the database and hands provisioning (identity realms, invitations) to the worker. Both run on every `up` and are no-ops when already loaded. To write the JSON locally instead:

```sh
pnpm seed                      # -> tools/seed/out/
pnpm seed -- --seed 7 --reports 5000
```

Since layer 4 the loader also fills the field roster (`tools/seed/src/county.ts`, `teams`): damage assessment teams, the CERT canvass team, a Guard traffic-control unit and ARES net control for the county; chainsaw crews, canteens, shelter staff and an outreach pair for the partner organizations, each member with recorded, verified credentials (DSP-02, PER-01), and a Field Exercise Team whose lead has a sign-in for the field app and the stack suites; the county's parcel grid (`cg.parcel`, FLD-04); and the exercise event's check-in code `WESTWIND` (FLD-03). Everything it produces is invented and marked `synthetic: true`. **Only synthetic or exercise data ever goes into this stack (SCL-12).**

Since layer 6 the loader also gives the exercise state and county their jurisdiction codes (`29` and the fictional `29999`), and the worker fills public reference data for them (tracts, structures, declarations and the like, ADR-0039). By default it replays the synthetic responses in `packages/refdata/recordings`; `REFDATA_MODE=live` in `.env` pulls from the free federal sources instead (only geography leaves the stack), and `off` pulls nothing. Staff with the planning/GIS role can ask for a pull now or import a CSV or GeoJSON file for any dataset (`/api/v1/refdata/...`).

## Run the checks

```sh
pnpm install
pnpm lint              # eslint + prettier
pnpm typecheck
pnpm check:product-name   # ADM-03: product name never hardcoded
pnpm test              # unit tests (vitest)
pnpm test:integration  # against the running stack (STACK_URL, COMPOSE_FILES to override): layer 1 to 6 acceptance cases
pnpm test:e2e          # Playwright + axe: resident flow, kiosk, console onboarding, review, needs board, sites, dispatch and missions journeys, the field app's web build, the public help page, the CJIS enclave and the console's enclave link (npx playwright install chromium first)
tests/load/run.sh submissions smoke   # k6 load profiles (SCL-03) through the pinned k6 container; also sms-sessions, help and field (positions and the live stream); `full` is the target profile, see tests/load/README.md
pnpm --filter @cg/web-help build && pnpm --filter @cg/web-help check:size   # PUB-07: the public page's first load against its 300 KB budget
pnpm --filter @cg/pdf samples out/pdf && pnpm --filter @cg/reporting samples out/pdf && pnpm --filter @cg/api samples out/pdf && scripts/verapdf.sh out/pdf   # ADR-0040: one PDF of every kind, each checked against PDF/UA-1 by veraPDF (Docker)
API_DB_TEST_APP_URL=... API_DB_TEST_WORKER_URL=... pnpm --filter @cg/worker load:generation smoke   # SCL-03: counting rule, IDA package and metrics timed for 1,000 reports (`full`: 50,000)
scripts/backup.sh && scripts/restore.sh backups/<stamp>   # NFR-05; drills in tests/drills/
DATABASE_MIGRATOR_URL=... pnpm --filter @cg/db check:migrations 3   # newest migrations up, down, up; dictionary and RLS checks (SEC-05/11)
pnpm --filter @cg/intake lint:strings   # INT-08: reading-grade table and tone findings for the question graph
pnpm --filter @cg/ai evaluate           # AIG-08: evaluation report against the test double (no network)
pnpm --filter @cg/ai evaluate:live      # AIG-08: the same set against OpenAI (needs OPENAI_API_KEY; paid calls)
pnpm --filter @cg/db check:migrations 1 # drill the newest migration up, down and up against the compose database (needs DATABASE_MIGRATOR_URL)
pnpm reqindex          # regenerate docs/requirements-index.md after editing docs/0*
eval "$(scripts/cjis-test-db.sh)" && pnpm vitest run --project unit packages/cjis-db/test services/cjis-api/test   # the enclave's database-backed suites on a throwaway enclave database (127.0.0.1:5433); scripts/cjis-test-db.sh --stop removes it
CJIS_DATABASE_MIGRATOR_URL=$CJIS_DB_TEST_MIGRATOR_URL pnpm --filter @cg/cjis-db check:migrations 5   # the enclave migration drill
```

On a fresh stack, run them in CI's order: `pnpm test:integration`, then the database-backed suites against the compose database (the command in the CI step that lists them), then `pnpm test:e2e`. The joint-assessment and equity journeys use the verified, geolocated reports those suites leave in the seeded county, and fail on a stack that has only the seed. The enclave suites share their tokens through `cg-enclave-otp-state.json` in the system temp folder and drop any signed by a key the current enclave realm no longer has, so they also work after `docker compose down -v`.

CI (`.github/workflows/ci.yml`) runs all of these plus Semgrep, Trivy dependency/secret/container scans (the enclave's `cjis-api` and `cjis-web` images included) and SBOMs. Image scans fail the build on fixed HIGH/CRITICAL findings in our layers and the Alpine packages; findings inside the upstream Caddy binary are reported without failing, because every Caddy release lags its Go libraries, and are cleared by bumping the pinned Caddy image (`compose.yaml`, `infra/web/Dockerfile`).

The field app (`apps/field`, Expo SDK 57, React Native) runs in a browser with `pnpm --filter @cg/field web` and on a device or emulator through a local build: `pnpm --filter @cg/field prebuild:android`, then Gradle or Android Studio (EAS cloud builds are not used, ADR-0014). Its platform-free core (outbox, sync, conflicts, purge, parcel snapping, USNG, sweep order, timers, location policy) is `packages/field-core`.
