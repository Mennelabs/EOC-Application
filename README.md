# Common Ground

A disaster community-response platform for county and city emergency management, NGOs and states: resident damage and needs reporting, staff review, needs sharing with partners, public "Find help", missions and dispatch, a field app, FEMA declaration support, a CJIS enclave, ICS/EOC functions and AI assistance.

The product name is configuration (`PRODUCT_NAME`, ADM-03). "Common Ground" is the current working name.

**Status:** first deliverables for review (requirements index, architecture, ADRs, scaffold, layer-1 plan). No feature code yet. Build order follows SCL-14, one layer at a time.

## Start the stack

Requirements: Docker Desktop (Compose v2), Node 24 (`.nvmrc`), pnpm 10 (`corepack enable`).

```sh
scripts/init-env.sh          # writes .env with random local secrets (never committed)
docker compose up -d --wait  # builds images, starts every service, waits for health
```

Then open:

| URL                        | What                                                                                                                                                         |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| https://localhost/         | Resident app (English/Spanish). Accept Caddy's local certificate once, or trust it: `docker compose cp gateway:/data/caddy/pki/authorities/local/root.crt .` |
| https://localhost/console/ | Staff console shell                                                                                                                                          |
| https://localhost/api/meta | API metadata; `/api/health/ready` lists dependency health                                                                                                    |
| https://localhost/auth/    | Keycloak (admin `cg-admin`, password in `.env`)                                                                                                              |
| http://localhost:8025      | Mailpit: every email the system sends                                                                                                                        |
| http://localhost:15672     | RabbitMQ management (`cg`, password in `.env`)                                                                                                               |
| http://localhost:9001      | MinIO console (`cg-local`, password in `.env`)                                                                                                               |

The CJIS enclave (`cjis-*` services) starts on its own internal network. It has no published ports on purpose: `docker compose exec cjis-api wget -qO- http://127.0.0.1:8080/health/ready`.

Maps (SCL-13) are opt-in because the first build downloads the Missouri OpenStreetMap extract: set `COMPOSE_PROFILES=maps` in `.env` for the geocoder and run `docker compose --profile maps-build run --rm tiles-build` once for vector tiles.

Behind a corporate proxy that inspects TLS, pass its CA to the builds: `docker compose build --build-arg HTTPS_PROXY=... ` and `--secret id=extra_ca,src=/path/ca.pem` (see `infra/node/Dockerfile`).

## Seed data

The `seed` service runs on every `up` and writes the synthetic county (tenants, areas, parcels, facilities, personnel, resident reports) to the `seed_data` volume. To write it locally instead:

```sh
pnpm seed                      # -> tools/seed/out/
pnpm seed -- --seed 7 --reports 5000
```

Everything it produces is invented and marked `synthetic: true`. Loading it into the database arrives with the layer-1 schema. **Only synthetic or exercise data ever goes into this stack (SCL-12).**

## Run the checks

```sh
pnpm install
pnpm lint              # eslint + prettier
pnpm typecheck
pnpm check:product-name   # ADM-03: product name never hardcoded
pnpm test              # unit tests (vitest)
pnpm test:integration  # against the running stack (STACK_URL, COMPOSE_FILES to override)
pnpm test:e2e          # Playwright + axe accessibility, desktop and phone (npx playwright install chromium first)
pnpm reqindex          # regenerate docs/requirements-index.md after editing docs/0*
```

CI (`.github/workflows/ci.yml`) runs all of these plus Semgrep, Trivy dependency/secret/container scans and an SBOM.
