# Find a survivor's record: accessibility record

Recorded 2026-10-16 with the survivor lookup (FL-02) and shared documents (FL-09). Four screens:

- **Find a survivor's record**, console (`/console/find-survivor`, `apps/web-console/src/screens/find-survivor.tsx`):
  - a paragraph saying the survivor shows it is them before anything is shown, and that every search is recorded;
  - a fieldset "How to find it" with two radio buttons: by phone, or by address and name;
  - by phone: a labelled phone field, "Text them a code", then "Code they read to you" (with its hint) and "Check the code"; the reports found are a table captioned "Reports on that phone", each reference code a link to the report;
  - by address and name: labelled street, optional ZIP and name fields (with hints) and "Search"; the matches are read back as a list headed "Read these back and ask which is theirs", each with a button "They say this one is theirs" that also names, for screen readers, the day and the channel; the result is a status line with the reference code and a link to the report.
- **Find a survivor's record**, field app (`apps/field/app/find.tsx`): the same two ways with the field app's own labelled fields, radio group and buttons, in English and Spanish; matches are buttons that say the day and the channel; the result is a card with the code.
- **Add a document they share**, field app (`apps/field/app/document.tsx`, FL-09, added 2026-10-16): radio groups for the document and the survivor's language; the question is shown in the survivor's language (marked with its language) for them to read; buttons "They said yes", "They tapped yes" and "They said no"; the outcome is an alert in words.
- **Documents they shared**, console report screen (`review.tsx`, FL-09): a button shows the list on request; each document is named in words with how the survivor agreed, the words in their language (marked with `lang`) and a link to the photo that says it opens a new tab.
