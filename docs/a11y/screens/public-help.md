Open before GATE-03 can be claimed in full for the public page: check 2 (a screen-reader pass by a person) and the professional Spanish review (EQ-07). The automated evidence runs on every push on desktop and phone.

"Sign up to volunteer" (`?view=volunteer&join=…`, FL:FR-20, 2026-10-16): the same page frame and language switch. Fields are labelled, grouped in fieldsets with legends ("About you", the skills, the waiver), and the hint about why a phone or email is asked is tied to both fields. Skills are checkboxes from a fixed list, so nothing personal is typed there. The county's waiver is shown as paragraphs, marked with its own language; when it exists only in English, the Spanish page says so and points to the desk. Errors are announced (`role="alert"`); on success the desk code is shown large and receives focus. A closed or expired code says to ask at the desk. `tests/e2e/console-screens.spec.ts` (FL:FR-20) runs axe on the form in Spanish and on the desk code in English, on desktop and phone.
