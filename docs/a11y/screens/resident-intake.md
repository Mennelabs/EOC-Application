# Resident intake (web, assisted/kiosk, my report, pause/resume) — accessibility record

Screens: welcome, safety, every question type (choice, picture choice, number, address, contact with the text-message opt-in), own words with dictation and "help me fill in the answers", photos, needs, consent, review, send, confirmation, optional questions, clear, my report (reference + one-time code), pause and resume, kiosk banner. English and Spanish. Layer 2, released 2026-10-12.
