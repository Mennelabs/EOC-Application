## Resume checklist

1. `pnpm install && pnpm typecheck && pnpm test && pnpm lint && pnpm check:product-name` green before new work.
2. Stack for integration work: `scripts/init-env.sh` (or `scripts\init-env.ps1`) then `docker compose up -d --wait`; the suites wait for provisioning on their own.
3. Pick the first task below that is not `done`, finish it to green, commit citing requirement IDs, update this file, push.

## Known issues and deferred items

- `pnpm.overrides.rolldown = 1.2.12` in `package.json`: the lockfile had rolldown 1.2.13 (published 2026-10-07), which the seven-day `minimumReleaseAge` rule refuses on any non-frozen install; the override pins the newest mature release. Remove it after 2026-10-14 when a Vite bump is wanted.

- Reference codes are never recycled: a leased code that an API instance loses (crash) stays leased; the space is 1.1 billion codes and the worker keeps 500 free per tenant.
- Direct photo uploads go to `https://objects.<GATEWAY_HOST>` (gateway site block, MinIO CORS for the app origin, API presigns with `S3_PUBLIC_ENDPOINT`); browsers resolve `objects.localhost` on their own, a custom host needs a matching DNS or hosts entry. Resumable multipart parts are not needed at the 1.5 MB cap (SCL-04 note in ADR-0028).
- See `layer-2.md` §11 for deferred IDs. Spanish strings are drafts pending professional translation and community review (EQ-07) and are marked as such in the resident app's message file.
- The geocoder profile (`COMPOSE_PROFILES=maps`) downloads the Missouri extract; intake never depends on it (SCL-06).
