## What passed

- **Checks on the final tree:** typecheck, lint, the ADM-03 product-name check, the unit suites (67 files, 410 cases), the requirements index unchanged; the fresh-database migration drill (145 tables, nothing undocumented, every table under row security, down two and up again).
- **One figure everywhere (GATE-07):** on the stack, the Declaration screen's housing units equal the metrics' damage figure and the IDA package the worker builds in its container, the situation map's tracts add up to no more, and the package downloads with the SHA-256 the worker recorded. In the database suites, the package's `summary.csv`, street sheet and GeoJSON agree with the Declaration screen; official report facts equal the counting rule as of the cutoff; the metrics' CSV and PDF carry the screen's totals.
- **Privacy (DCL:DEC-13, EQ-13):** no street address, reference code or parcel number in any package file; validators and the state liaison see counts and 100 m cells only; equity counts from 1 to 10 hidden with anything worked out from them; the resident's own copy leaves out who they are, how to reach them, their household and their needs.
- **Guardrails:** the author cannot review or issue a report (G4); nobody marks a home whose degree they set; an API key or webhook is never approved by the one who asked (G6), and is frozen during break-glass; every bad API key gets the same refusal; a key in a GIS client's URL never reaches the API log.
- **Accessibility:** veraPDF passes all nine PDF kinds as PDF/UA-1; axe and a reflow check pass on every state of the ten layer-6 console journeys and the resident journey, on desktop and phone.
- **Load (SCL-03):** for 50,000 synthetic reports (23,422 homes) the counting rule took 1.2 s, the IDA package with its PDF and zip 13.9 s, and the metrics 2.5 s, each well inside the 60-second target; the 1,000-report smoke runs in CI.

## What did not pass, or is not yet proven

- **CI on the final head** is the merge condition. Run 196 failed on a typecheck error in a test helper call (`body['keys']` typed as `Array.prototype.keys`); fixed in `1cbee77`. Run 191 found a reply sent before its commit in the enclave narrative route; fixed with a stronger guard in `dfe6c76`.
- **Live federal sources** were not reachable from this build environment; connectors follow the published formats and are checked against recorded responses. You run the live check in production.
- **FEMA's current form versions** could not be fetched (fema.gov blocked here). The v1 mappings follow `docs/05`; compare them with fema.gov/pda before the pilot and put any new edition in force from the console (DCL:DEC-12, DEC-15).
- **Screen-reader passes** of the new screens and PDFs need a person with NVDA and VoiceOver (each screen's record in `docs/a11y/screens`).
- **Partial rows with their gaps** (the traceability file names each): metrics without status and severity filters or utilization (BRD:FR-14.02/14.04); MET-02, 04, 07 and 10 measured in part; partners' meals, cleanup teams and donated goods not summarized (DCL:DEC-09); donated equipment not logged (FL-17); road closures not a map layer, outages placed only when their facility is known (CON-03); Survey123 import of routes and parcels not built (CON-17); the intake full load profiles still need a sized host (SCL-03).
- **Existing tenants** get the new actions only through a role change approved by a second administrator; new tenants get them from the templates. A release note for a live county must say so.
- Found and fixed on the way: a layer-4 bug that refused every field assessment with "damage seen" boxes (`1a2eea7`); the photo thumbnail made from the unblurred image (`d79b572`); a version bump on every API-key use that would have made revokes fail while a key was in use (fixed before commit).

## Readings taken in favour of privacy and accuracy (flagged for you)

The plan's §12 lists all 25 with their reasons. In short: the counting rule (approved and verified only, exclusions shown, per unit, unknown never zero); no personal details in any package or export unless a signed agreement names more; low income only as a tract aggregate; casualties only from staff with an official source; representative photos only when a detector has blurred them and a person confirms; validators see no address; the liaison's view needs a signed agreement and stays counts only; API keys and webhooks need a second administrator and webhooks reach only public HTTPS hosts; the feature service refuses what it cannot answer exactly; the resident's own copy holds the home and the damage only; the situation map's equity layer never flags by colour alone and hides small numbers.
